## 🙋 Introduce

안녕하십니까. **서비스 품질에 집중하는 개발자 취업준비생 유민재**입니다.

2019년부터 Java를 중심으로 개발 공부를 시작했으며, 프로젝트에서는 주로 **백엔드 개발과 DB 설계**를 담당했습니다.

AI를 활용한 개발 방식이 확산되는 환경에서 백엔드 개발자의 차별화된 경쟁력은 **서비스의 품질을 어떻게 높일 수 있는지 이해하고 실천하는 능력**이라고 생각합니다. 이에 삼성 청년 SW·AI 아카데미(SSAFY)에서 진행한 프로젝트에서는 AWS를 활용해 인프라를 직접 구축했고, 기존 백엔드 개발 경험을 바탕으로 서비스의 안정성과 성능을 고려한 아키텍처 설계에도 도전했습니다.

저에게 **좋은 서비스는 사용자가 편리하게 이용할 수 있는 서비스**입니다. 앞으로도 고객이 좋은 서비스를 이용할 수 있도록 개발과 품질 개선에 주도적으로 기여하는 개발자가 되겠습니다. 많은 응원 부탁드립니다!
